# Keychron J5 - Hardware Design Files

> 100% full-size QMK wireless mechanical keyboard with 2.4 GHz, Bluetooth, and USB-C wired connectivity.

**Product page:** [Keychron J5 QMK Wireless Mechanical Keyboard](https://www.keychron.com/products/keychron-j5-qmk-wireless-mechanical-keyboard)

![Keychron J5](https://cdn.shopify.com/s/files/1/0059/0630/1017/files/Keychron-J5-QMK-Wireless-Mechanical-Keyboard-page3.jpg?v=1757924236)

## Specifications

| Spec | Detail |
|---|---|
| Layout | 100% full-size |
| Connectivity | 2.4 GHz / Bluetooth / USB-C wired |
| Firmware | QMK / Keychron Launcher |
| Hot-swap | Yes, depending on version |
| Plate Material | Aluminum |
| Keycaps | Double-shot PBT |
