# Keychron V4 QMK - Hardware Design Files

> 60% wired QMK custom mechanical keyboard with a hot-swappable PCB and ABS case.

**Product page:** [Keychron V4 QMK Custom Mechanical Keyboard](https://www.keychron.com/products/keychron-v4-qmk-custom-mechanical-keyboard)

![Keychron V4 QMK](https://cdn.shopify.com/s/files/1/0059/0630/1017/products/Keychron-V4-QMK-VIA-custom-mechanical-keyboard-60-percent-layout-frosted-black-for-Mac-Windows-iOS-RGB-backlight-with-hot-swappable-Keychron-K-Pro-switch-red-V4-A1.jpg?v=1660558152)

## Specifications

| Spec | Detail |
|---|---|
| Layout | 60% |
| Body Material | ABS plastic |
| Plate Material | Steel |
| Mount | Tray mount |
| Connectivity | Wired |
| Polling Rate | 1000 Hz |
| Switch Support | Hot-swappable 3-pin and 5-pin MX mechanical switches |
| Keycaps | Double-shot OSA PBT (fully assembled version) |
| Backlight | South-facing RGB |
| Firmware | QMK / Keychron Launcher |
| Compatibility | macOS / Windows |
| Dimensions | 303.85 × 117.09 mm |
| Weight | 730 ± 10 g (fully assembled version) |
