# Keychron B2 Pro - Hardware Design Files

> Ultra-slim 96% wireless keyboard with 2.4 GHz, Bluetooth, wired connectivity, and Keychron Launcher customization.

**Product page:** [Keychron B2 Pro Ultra-Slim Wireless Keyboard](https://www.keychron.com/products/keychron-b2-pro-ultra-slim-wireless-keyboard)

![Keychron B2 Pro](https://cdn.shopify.com/s/files/1/0059/0630/1017/files/Keychron-B2-Pro-Space-Gray.jpg?v=1746776368)

## Specifications

| Spec | Detail |
|---|---|
| Layout | 96% / ANSI |
| Number of Keys | 98 |
| Body Material | ABS |
| Keycap Material | ABS |
| Backlight | Non-backlit |
| Connectivity | 2.4 GHz / Bluetooth 5.2 / USB-C wired |
| Polling Rate | 1000 Hz (2.4 GHz and wired) / 90 Hz (Bluetooth) |
| Battery | 800 mAh rechargeable li-polymer |
| Wireless Working Time | Up to 300 hours |
| Firmware | Keychron Launcher / ZMK |
