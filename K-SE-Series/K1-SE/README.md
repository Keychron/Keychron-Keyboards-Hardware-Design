# Keychron K1 SE - Hardware Design Files

> Ultra-slim tenkeyless wireless mechanical keyboard with Bluetooth 5.1, USB-C wired mode, and support for macOS and Windows.

**Product page:** [Keychron K1 SE Wireless Mechanical Keyboard (Version 5)](https://www.keychron.com/products/keychron-k1-se-wireless-mechanical-keyboard)

![Keychron K1 SE](https://www.keychron.com/cdn/shop/files/keychron-K1-SE-Ultra-slim-Wireless-Custom-Keyboard-1.jpg?v=1787731905)

## Specifications

| Spec | Detail |
|---|---|
| Layout | 80% / TKL / US ANSI |
| Profile | Low-profile |
| Connectivity | Bluetooth 5.1 / USB-C wired |
| Switch Type | Low Profile Gateron Mechanical / Low Profile Keychron Optical |
| Hot-swap | Available on Keychron Optical and selected Gateron Mechanical versions |
| Case Material | Aluminum top case / ABS bottom case |
| Backlight | White backlight / RGB backlight, depending on version |
| Polling Rate | 1000 Hz (wired) / 90 Hz (Bluetooth) |
