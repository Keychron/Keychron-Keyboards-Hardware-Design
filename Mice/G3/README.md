# Keychron G3 - Hardware Design Files

> Ultra-light wireless gaming mouse with PixArt 3950 sensor, 8K polling, tri-mode connectivity, and a 44 g body.

**Product page:** [Keychron G3 Ultra Light Wireless Mouse](https://www.keychron.com/products/keychron-g3-ultra-light-wireless-mouse)

![Keychron G3](https://www.keychron.com/cdn/shop/files/G3-Mouse-Black.jpg?v=1775788897)

## Specifications

| Spec | Detail |
|---|---|
| Type | Wireless gaming mouse |
| Shape | Symmetrical |
| Weight | 44 g |
| Sensor | PixArt 3950 |
| DPI | 100 - 30000 |
| Polling Rate | Up to 8000 Hz (2.4 GHz / wired) |
| Connectivity | 2.4 GHz / Bluetooth 5.3 / USB-C wired |
| Switch | Huano micro switch |
| Battery | 500 mAh |
| Body Material | ABS + PC / ABS + Carbon Fiber |
