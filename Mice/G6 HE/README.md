# Keychron G6 HE - Hardware Design Files

> Ultra-light wireless competitive gaming mouse with G6 HE and Turbo Link 8K receiver design files.

**Product brief:** [Keychron G6 HE](https://keychron.kr/news/g6-he-brief/)

![Keychron G6 HE](assets/keychron-g6-he-wireless-mouse.jpg)

## Specifications

| Spec | Detail |
|---|---|
| Type | Wireless competitive gaming mouse |
| Shape | Symmetrical |
| Sensor | PixArt PAW3955 |
| Polling Rate | Up to 8000 Hz (2.4 GHz / wired) |
| Connectivity | Bluetooth 5.3 / 2.4 GHz / USB-C wired |
| Switch | MagOptic adjustable-actuation switch |
| Body Material | ABS + PC |
