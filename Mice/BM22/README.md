# Keychron BM22 - Hardware Design Files

> Lightweight wireless office mouse with PAW3212 sensor, tri-mode connectivity, and 1K polling rate.

**Product page:** [Keychron BM22 Wireless Mouse](https://www.keychron.com/products/keychron-bm22-wireless-mouse)

![Keychron BM22](https://cdn.shopify.com/s/files/1/0059/0630/1017/files/Keychron_BM22_Wireless_Mouse-6.jpg?v=1754550406)

## Specifications

| Spec | Detail |
|---|---|
| Type | Wireless office mouse |
| Shape | Symmetrical ergonomic |
| Weight | 76 +- 3 g |
| Sensor | PAW3212 |
| DPI | 100 - 2400 |
| IPS | 30 |
| Polling Rate | Max 1000 Hz (2.4 GHz / wired), Max 125 Hz (Bluetooth) |
| Connectivity | Bluetooth 5.2 / 2.4 GHz / USB-C wired |
| Switch | Huano micro switch |
| Battery | 450 mAh |
| Body Material | ABS |
