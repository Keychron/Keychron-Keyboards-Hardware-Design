# Keychron G9 HE - Hardware Design Files

> Ultra-light tri-mode competitive gaming mouse with G9 HE and Turbo Link 8K receiver design files.

![Keychron G9 HE](assets/keychron-g9-he-wireless-mouse.jpg)

## Specifications

| Spec | Detail |
|---|---|
| Type | Wireless competitive gaming mouse |
| Shape | Symmetrical ergonomic |
| Dimensions | 118 x 61.3 x 39 mm |
| Weight | Approx. 42 g +/- 3 g |
| Sensor | 3955 (up to 40000 DPI) |
| Polling Rate | Up to 8000 Hz |
| Connectivity | Bluetooth 5.3 / 2.4 GHz / USB-C wired |
| Switch | Keychron MagOptic hybrid micro switch |
| Battery | 350 mAh |
