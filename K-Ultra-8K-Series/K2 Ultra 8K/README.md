# Keychron K2 Ultra 8K - Hardware Design Files

> 75% compact wireless custom mechanical keyboard with 2.4 GHz, Bluetooth, and wired connectivity, ZMK firmware, Keychron Launcher customization, an 8K polling rate, a CNC aluminum frame, and up to 760 hours of battery life.

**Product page:** [Keychron K2 Ultra 8K](https://www.keychron.com/products/keychron-k2-ultra-8k-wireless-custom-mechanical-keyboard)

![K2 Ultra 8K](https://cdn.shopify.com/s/files/1/0059/0630/1017/files/Keychron-K2-Ultra-Features-1.jpg?v=1781071795)

## Specifications

| Spec | Detail |
|---|---|
| Layout | 75% compact |
| Versions | Fully Assembled |
| Body Material | CNC Aluminum + ABS |
| Bottom Case Material | ABS |
| Plate Material | Steel |
| Switch Type | Keychron Apex Switch |
| Keycap | OSA double-shot PBT keycaps, non-shine-through |
| Connectivity | 2.4 GHz / Bluetooth 5.2 / Type-C Wired |
| Polling Rate | 8000 Hz / 2000 Hz / 1000 Hz |
| Battery | 4000 mAh, up to 760 hours |
| Firmware | ZMK / Keychron Launcher |
