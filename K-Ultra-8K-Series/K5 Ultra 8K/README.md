# Keychron K5 Ultra 8K - Hardware Design Files

> Ultra-slim 100% full-size wireless custom mechanical keyboard with 2.4 GHz, Bluetooth, and wired connectivity, ZMK firmware, Keychron Launcher customization, an 8K polling rate, a natural wood and aluminum frame, and up to 370 hours of battery life.

**Product page:** [Keychron K5 Ultra 8K](https://www.keychron.com/products/keychron-k5-ultra-8k-wireless-custom-mechanical-keyboard)

![K5 Ultra 8K](https://www.keychron.com/cdn/shop/files/Keychron-K5-Ultra-8K-Wireless-Custom-Mechanical-Keyboard-1_d1e95f4a-5106-4a47-8946-32e2ec9e09a6.jpg?v=1781238524)

## Specifications

| Spec | Detail |
|---|---|
| Layout | 100% full-size slim |
| Versions | Fully Assembled |
| Body Material | Aluminum + Wood |
| Bottom Case Material | ABS Plastic |
| Plate Material | Anodized Aluminum Alloy |
| Switch Type | Keychron Milk POM Switch |
| Keycap | LSA double-shot PBT keycaps, non-shine-through |
| Connectivity | 2.4 GHz / Bluetooth 5.2 / Type-C Wired |
| Polling Rate | 8000 Hz / 125 Hz Bluetooth |
| Battery | 2600 mAh, up to 370 hours |
| Firmware | ZMK / Keychron Launcher |
