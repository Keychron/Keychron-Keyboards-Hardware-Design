# Keychron Orca Echo - Hardware Design Files

> Compact split ergonomic keyboard files for Orca Echo, a portable layout-focused keyboard with an integrated trackball, vertical scrolling controls, magnetic storage, and deep keymap customization.

![Keychron Orca Echo](./orca-echo-product.png)

## Specifications

| Spec | Detail |
|---|---|
| Layout | Compact split ergonomic |
| Integrated Controls | Trackball (right): cursor movement, with mouse clicks on the "Fn1" layer<br>Touchpads (both halves): vertical scrolling, tap to click<br>Thumb wheel (left): volume control<br>All controls, including the trackball, are customizable |
| Connectivity | Wired / Bluetooth 5.2 with 3 channels / 2.4 GHz |
| Firmware | ZMK |
| Switches | Linear / Tactile options |
| Rollover | NKRO |
