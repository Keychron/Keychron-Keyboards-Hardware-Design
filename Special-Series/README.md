# Special Series - Hardware Design Files

> Hardware design files for Keychron special products, including Paw Key and Orca Echo.

Part of the [Keychron Hardware Design](https://github.com/Keychron/Keychron-Keyboards-Hardware-Design) repository.

## Available Models

| Model | Type / Layout | Integrated Controls | Firmware | Status |
|---|---|---|---|---|
| [Paw Key](./Paw%20Key/README.md) | Big Kitty Paw Key | Programmable key | QMK | Files published |
| [Orca Echo](./Orca/README.md) | Compact split ergonomic keyboard | Trackball, touchpads, and left thumb wheel | ZMK | Files published |

## Repository Contents

This series includes the Paw Key and Orca Echo model folders, with product images and published downloads hosted on Keychron's official server. Orca Echo supports portable magnetic storage and deep keymap customization.

## Download Files

| File | Description | Format |
|---|---|---|
| [Paw Key files](./Paw%20Key/README.md#downloads) | Paw Key 3D CAD model | STP |
| [Orca Echo files](./Orca/README.md#downloads) | Left and right top cases, bottom cases, PCB, plates, and full-model hardware files | STP / DWG / PDF |

## Opening the Files

| Format | Free Software | Commercial Software |
|---|---|---|
| `.stp` | FreeCAD, Onshape | Fusion 360, SolidWorks |
| `.dwg` | LibreCAD (limited), QCAD | AutoCAD, DraftSight |
| `.pdf` | Any PDF viewer | - |
